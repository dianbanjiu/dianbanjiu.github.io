Windows 下使用 Alt-Tab 切换窗口的时候虽然很简洁直观，但是当窗口比较多的时候，每次都得找半天，一直期待微软官方能不能给这个工具加上个搜索之类的，这样他真的就算是比较完美的，可惜到了 Windows 11 也没能如愿。所以我就一直在找有没有类似的替代品。  

最初是发现了 [Switchroo](https://github.com/kvakulo/Switcheroo) 这个工具，看介绍在功能够用的情况下也很小巧，才几百KB的大小，对比现在动辄上百MB大小的工具来说简直是一股清流。  
但是实际使用之后，不知道是不是因为很久没有更新的缘故，经常会出现无法唤起的情况。而且使用起来其实也不算非常顺手，在按下 Alt+Tab 之后，我必须在不松开 Alt 的情况下按其他字母进行搜索，虽然他也提供了设置可以让 Alt+Tab 直接让窗口列表在松开按键的情况下也一直展示着，但是这种情况下我必须在找到对应的窗口之后再按回车来打开对应的窗口。我其实更想这两个功能能快速的进行切换，大多数时候窗口就在附近的话我可以通过几次tab直接到对应的窗口，然后松开 alt 就可以打开窗口。如果窗口比较多，并且需要的窗口又在靠下位置的时候，我可以在无需一直保持 alt 键被按下的情况下快速进入搜索模式，通过搜索定位到对应的的窗口。  

但是再找来找去也一直没有发现更好用的类似工具了。  

得益于最近 AI 的疯狂发展，让我能在对客户端开发毫无了解的情况下，也能直接拿着我的 token 根据自己的需求开发出这款窗口切换器 [Flipswitcher](https://github.com/dianbanjiu/Flipswitcher)。  
从去年12月开始我根据自己的使用体验陆陆续续调整开发到了现在，几乎完美解决了我之前在 Switchroo 上遇到的那些痛点，在这半年时间它也确实成为了我使用最多的工具之一，甚至可以说没有之一，因为窗口切换这个动作实在是频繁到让人太习以为常了。  

关于这个工具更详细的一些说明，可以在 [官网](https://flipswitcher.djangozane.com/) 上查看

不过有一个比较遗憾的地方是，原本Windows窗口切换器的是有预览效果，可以直接看到这个窗口目前大概的样子，我其实还是比较喜欢那个功能的，但是如果做这个功能，给工具带来的负面效果更大，所以最终评估了一下还是放弃了
